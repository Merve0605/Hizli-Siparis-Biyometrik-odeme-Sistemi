# Hizli-Siparis-Biyometrik-odeme-Sistemi

Yüz tanıma, parmak izi ve kart/nakit seçenekleriyle çalışan modern web tabanlı hızlı sipariş ve biyometrik ödeme sistemi. E-Arşiv fatura kesimi, canlı GPS kurye takibi, dışarıdan özel restoran/yiyecek tahsilatı ve kişiselleştirilmiş sepet yönetimi sunar. Mobil ve masaüstü tarayıcılarla tam uyumludur.
